# Taigan

Приложение для Mac со значком в верхней панели. Бесплатно.

- **Раскладка.** Слово, набранное не в той раскладке, исправляется само. Option переключает язык.
- **Буфер.** Пять последних копий текста и картинок, правый Shift открывает список.
- **Снимки экрана.** Левый Control, миниатюра сбоку, пять последних снимков в меню.
- **Диктовка.** Держите fn и говорите, текст появится там, где курсор.

Всё работает на самом Mac. То, что вы печатаете, говорите, копируете и снимаете, в интернет не уходит.
Раз в день Taigan только смотрит здесь номер новой версии и, если вы согласитесь, обновляется сам.

## [Скачать Taigan.dmg](https://github.com/korobeinikov-ai/taigan/releases/latest/download/Taigan.dmg)

macOS 15 и новее, чипы Apple и Intel.

## Как поставить
1. Скачайте файл по ссылке выше в браузере.
2. Откройте Taigan.dmg и перетащите Taigan в «Программы».
3. Запустите Taigan из «Программ». Значок появится в верхней панели, Mac попросит разрешения.

Если файл прислали через Telegram, WhatsApp или другой мессенджер, Mac может не открыть программу.
Скачайте её по ссылке выше.
